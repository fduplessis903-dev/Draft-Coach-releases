# Draft Coach — downloads

Download page for Draft Coach. Only the installer lives here; there is no code in this repo.

## Install

1. Open **[Releases → latest](../../releases/latest)** and download `Draft-Coach-Setup-x.y.z.exe`.
2. Run it. Windows may show **"Windows protected your PC"** because the app isn't signed with a paid certificate: click **More info → Run anyway**. You only see this once.
3. Draft Coach starts and puts a shortcut on your desktop. Open League and it connects by itself.

## Updates

The app updates itself. When a new version is out it downloads in the background and asks **Restart to update**.

Draft Coach reads your own League client on your PC. It doesn't read the game, give live in-game advice or send anything to Riot. It isn't endorsed by Riot Games.
